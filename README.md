## 📖 Повний конспект теорії

### 1. Оператор розгалуження `if`
Оператор `if` виконує блок коду **тільки тоді**, коли зазначена в круглих дужках умова обчислюється як істинна (`truthy`).

```javascript
if (умова) {
  // код виконується лише якщо умова === true
}
```

#### 🛡️ Best Practice: Guard Clauses (Захисні барʼєри)
Замість огортання всієї функції у великий блок `if`, перевіряйте граничні випадки на самому початку та негайно виходьте з функції:

```javascript
// ❌ Глибока вкладеність:
function processPayment(user, amount) {
  if (user) {
    if (user.isVerified) {
      if (user.balance >= amount) {
        // дія...
      }
    }
  }
}

// ✅ Guard Clauses (чистий плоский код):
function processPayment(user, amount) {
  if (!user) return false;
  if (!user.isVerified) return false;
  if (user.balance < amount) return false;

  user.balance -= amount;
  return true;
}
```

### 2. Оператор розгалуження `if - else`
Коли у вас рівно два взаємовиключні сценарії: один для `true`, другий для `false`.

```javascript
if (умова) {
  // гілка ТАК (True)
} else {
  // гілка НІ (False)
}
```

> **Правило чистоти коду**: Якщо в обох гілках повертається значення через `return`, ключове слово `else` можна опустити.

---

### 3. Сходи розгалужень `if - else if - else`
Застосовується, коли є більше двох варіантів вибору, що перевіряються послідовно зверху вниз. Перша умова, що поверне `true`, виконає свій блок, а решта буде проігнорована.

```javascript
function getDiscount(yearsOfLoyalty) {
  if (yearsOfLoyalty >= 5) {
    return 0.20; // 20%
  } else if (yearsOfLoyalty >= 2) {
    return 0.10; // 10%
  } else if (yearsOfLoyalty >= 1) {
    return 0.05; // 5%
  } else {
    return 0;    // Без знижки
  }
}
```

### 4. Мова блок-схем: Позначення умов та обʼєднання гілок

Блок-схеми допомагають проектувати алгоритми до написання коду. Міжнародний стандарт ISO/DIN визначає ключові геометричні фігури:

#### 🔷 1. Блок умови (Decision Diamond)
* **Форма**: Ромб.
* **Призначення**: Задає питання (умову), що передбачає відповідь «ТАК» (істина) або «НІ» (хибність).
* **Входи/Виходи**: Завжди має **1 вхідну лінію зверху** та **2 вихідні стрілки** (зазвичай праворуч або ліворуч — «Так», донизу — «Ні»).

```
          │ Вхідний потік
          ▼
       ┌──────┐
      ╱ Умова? ╲ ───[ТАК]──► [Дія A]
      ╲        ╱
       └──────┘
          │ [НІ]
          ▼
       [Дія B]
```

#### ⭕ 2. Позначення обʼєднання гілок (Merge Point / Junction)
* **Форма**: Кружечок злиття потоків або точка зʼєднання стрілок перед наступним кроком.
* **Призначення**: Після виконання альтернативних дій (гілки «Так» або «Ні») потоки керування сходяться в одну точку, і програма продовжує спільний лінійний рух.

```
      [Дія A]       [Дія B]
         │             │
         └───► ● ◄─────┘  <── Точка злиття (Merge Node)
               │
               ▼
        [Наступна дія]
```

#### 📐 Приклади побудови програм мовою блок-схем:
1. **Визначення знака числа (`> 0`, `< 0`, `=== 0`)**:
   - Ромб 1: `x > 0`? ➔ ТАК: `"positive"`.
   - НІ ➔ Ромб 2: `x < 0`? ➔ ТАК: `"negative"`.
   - НІ ➔ Гілка за замовчуванням: `"zero"`.
   - Всі три виходи сходяться у спільний блок завершення.
2. **Алгоритм банкомата (ATM Withdrawal)**:
   - Вхід: баланс, запитана сума, ліміт купюр.
   - Ромб 1: `сума % 50 === 0`? (кратність). Якщо ні ➔ помилка кратності.
   - Ромб 2: `баланс >= сума`? Якщо ні ➔ «Недостатньо коштів».
   - Успішна видача готівки ➔ обʼєднання потоків та повернення чека.

### 5. Тернарний оператор (`? :`)
Єдиний оператор у JavaScript, що приймає **три операнди**. Це вираз (expression), а отже, він повертає значення, яке можна присвоїти змінній або передати в функцію.

```javascript
// Синтаксис:
const результат = умова ? значення_якщо_true : значення_якщо_false;

// Приклад:
const status = isOnline ? 'В мережі' : 'Офлайн';
```

#### Ланцюжковий тернарний оператор (Chained Ternary):
```javascript
const tier = points >= 1000 ? 'Platinum'
           : points >= 500  ? 'Gold'
           : points >= 100  ? 'Silver'
           : 'Bronze';
```
> ⚠️ **Порада**: Не зловживайте глибокими тернарними ланцюжками, якщо вони погіршують читабельність коду.

### 6. Оператор множинного вибору `switch`

Коли одну змінну потрібно порівняти на сувору рівність (`===`) з багатьма фіксованими значеннями, `switch` значно зручніший та охайніший за довгі сходи `if - else if`.

#### 🏛️ Синтаксис:
```javascript
switch (вираз) {
  case значення1:
    // команди для значення1
    break;

  case значення2:
    // команди для значення2
    break;

  default:
    // виконується, якщо жоден case не збігся
}
```

#### ❓ Що таке `switch`?
Ключове слово, яке відкриває блок багатоваріантного вибору. Значення в дужках обчислюється один раз і порівнюється з кожним `case`.

#### 🎯 Що таке `case`?
Мітка варіанта. Порівняння відбувається за **суворою рівністю** (`===` без приведення типів). Рядок `'5'` не співпаде з числом `5`.

#### 🛑 Що таке `break`?
Команда **негайного виходу** з блоку `switch`.  
Якщо пропустити `break`, виникає явище **`fall-through` (провалювання)**: виконання просто піде вниз у наступний `case`, навіть якщо його умова не збіглася!

```javascript
// Провалювання (fall-through):
const role = 'editor';
switch (role) {
  case 'admin':
    console.log('Повний доступ');
  case 'editor':
    console.log('Редагування'); // надрукує це...
  case 'viewer':
    console.log('Перегляд');    // ...і надрукує це теж, бо немає break!
}
```

#### 🛡️ Що таке `default`?
Необов'язкова секція (аналог фінального `else`), яка спрацьовує, якщо жоден `case` не збігся з перевірюваним виразом.

#### 👥 Свідоме групування кейсів (Multi-case Matching):
Завдяки поведінці `fall-through` можна обʼєднувати однакову логіку для різних значень:

```javascript
function getDayCategory(day) {
  switch (day.toLowerCase()) {
    case 'субота':
    case 'неділя':
      return 'Вихідний день 🎉';
    
    case 'понеділок':
    case 'вівторок':
    case 'середа':
    case 'четвер':
    case 'пʼятниця':
      return 'Робочий день 💼';

    default:
      return 'Невідомий день';
  }
}
```
