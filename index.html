    📖 Повний теоретичний довідник: Розгалуження та Блок-схеми
    

      
    1. Оператор розгалуження if
    
      
    
        Оператор if обчислює вираз у круглих дужках і перетворює результат до булевого типу (truthy / falsy).
        Якщо умова істинна — виконується блок коду у фігурних дужках. Якщо хибна — блок ігнорується, і програма переходить до наступного рядка.
      
    
      
    if (isVip) {
  balance += 100; // виконається тільки якщо isVip === true
}
    

      
    2. Оператор розгалуження if - else
    
      
    
        Коли задача вимагає виконати рівно одну з двох альтернативних дій, використовується if - else.
        Гілка else гарантує виконання, якщо умова виявилася хибною.
      
    
      
    if (number % 2 === 0) {
  return 'even'; // парне
} else {
  return 'odd';  // непарне
}
    

      
    3. Сходи if - else if - else (Множинні альтернативи)
    
      
    
        Якщо існує кілька взаємовиключних діапазонів або умов (наприклад, шкала оцінок або градація ваги),
        використовують сходи розгалужень. JavaScript перевіряє умови послідовно зверху вниз до першого збігу:
      
    
      
    if (score >= 90) {
  return 'Відмінно';
} else if (score >= 75) {
  return 'Добре';
} else if (score >= 60) {
  return 'Задовільно';
} else {
  return 'Незадовільно';
}
    

      
    4. Позначення умов у блок-схемах: Блок умови
    
      
    
        У графічній нотації алгоритмів блок розгалуження позначається символом ромба (◇).
        Всередині ромба записується логічне питання (наприклад, x > 0 ?).
        Ромб має обов'язково один вхід і два виходи:
      
    
      
      
        
    • «Так» (True, +) — потік дій, якщо умова виконується.
      • 
        
    • «Ні» (False, -) — потік дій, якщо умова не виконується.
      • 
      
    

      
    
        
    Символ блоку умови (Ромб)
    
        
      
    

      
    5. Позначення обʼєднання гілок у блок-схемах (Merge Point)
    
      
    
        Після виконання дій у різних гілках розгалуження лінії потоку мають знову зійтися в одну спільну точку перед переходом до наступних інструкцій або кінця програми.
        Місце злиття гілок позначається точкою сходу стрілок або маленьким кружком ○.
      
    

      
    
        
    Блок-схема розгалуження if-else з вузлом об'єднання
    
        
      
    

      
    6. Тернарний оператор (Conditional Operator ? :)
    
      
    
        Тернарний оператор — це лаконічна однорядкова форма if - else, яка повертає значення:
      
    
      
    const status = isOnline ? 'В мережі' : 'Офлайн';
    
      
    
        Ланцюжковий тернарний оператор: використовується, коли потрібно компактно розгалузити кілька значень без зайвих рядків:
      
    
      
    const rate = income <= 10000 ? 5 : income <= 50000 ? 10 : 20;
    

      
    7. Оператор множинного вибору switch
    
      
    
        Оператор switch замінює довгі сходи if (x === 'a') ... else if (x === 'b') ...,
        коли перевіряється точний збіг однієї змінної з кількома фіксованими значеннями.
      
    

      
    Синтаксис switch:
    
      
    switch (вираз) {
  case значення_1:
    // інструкції
    break;
  case значення_2:
    // інструкції
    break;
  default:
    // виконується, якщо жоден case не підійшов
}
    

      
    Розбір ключових понять switch:
    
      
      
        
    • Що таке switch? — Ключове слово, яке приймає вираз для оцінки. Усі перевірки здійснюються за суворою рівністю (аналог ===, без приведення типів: рядок "5" не збіжиться з числом 5).
      • 
        
    • Що таке case? — Мітка значення. Якщо значення у switch строго дорівнює значенню після case, потік виконання переходить сюди.
      • 
        
    • Що таке break? — Оператор негайного виходу з тіла switch. Якщо забути break, виконання провалиться (fallthrough) у наступний case незалежно від того, чи збігається його умова!
      • 
        
    • Що таке default? — Аналог фінального else. Спрацьовує, якщо жоден із блоків case не дав збігу.
      • 
        
    • Групування case: Якщо кілька різних значень вимагають однакової дії, їх записують поспіль без break:
      • 
      
    

      
    switch (day) {
  case 1:
  case 2:
  case 3:
  case 4:
  case 5:
    return 'Робочий день';
  case 6:
  case 7:
    return 'Вихідний день';
  default:
    return 'Невідомий день';
}
